# Qt_OCC CAD アプリケーション

Qt_OCCは、ユーザーインターフェースにQtフレームワーク、ジオメトリおよび視覚化カーネルにOpenCASCADE Technology (OCCT) を使用したデスクトップCAD／点群アプリケーションです。3Dモデリング、点群表示、操作、計測、解析機能を提供します。

## ✨ 機能

### 📂 ファイル管理
*   **CAD 入出力**: STEP/IGESモデルのインポートと、対応するCAD形式へのエクスポート。
*   **点群インポート**: `.xyz`、`.txt`、`.pts`、`.ply`の点群ファイルをインポート。

### 🎥 視覚化とナビゲーション
*   **標準ビュー**: 等角投影(Isometric)、上面、下面、左側面、右側面、前面、背面ビューを素早く切り替え。
*   **表示モード**: ワイヤーフレーム、シェーディング、隠線、エッジ付きシェーディング、白黒のレンダリングスタイルを切り替え、ビューの背景色を変更できます。
*   **ビュー制御**: ビューをシーン全体に自動フィット。

### ☁️ 点群
*   **対応データ**: XYZ、XYZRGB、点数ヘッダーが省略可能なPTS、ASCII PLY、Binary Little Endian PLY。
*   **OCCTネイティブ表示**: 各点をトポロジ頂点に変換せず、`AIS_PointCloud`で表示。
*   **表示制御**: 表示／非表示、ビューへのフィット、削除、点サイズ変更、表示設定のリセット。
*   **カラーモード**: 元のRGB、指定した単色、またはZ高さに基づくカラー表示。
*   **点群情報**: 元レコード数、有効点数、表示点数、無効レコード、RGB状態、ファイルサイズ、境界、寸法を確認。
*   **大規模ファイル保護**: ワーカースレッドで読み込み、進捗表示とキャンセルに対応。表示上限は500K、1M、2M、5M、全点から選択でき、上限超過時は均等サンプリングを使用。
*   **CAD/CAE分離**: 点群をトポロジ依存のモデリング、計測、エクスポート、干渉、CAE処理から分離。

### 🛠️ モデリングツール
*   **2D プリミティブ**: 点、線、長方形、円、円弧、楕円、ポリゴン、ベジェ曲線、NURBS曲線の作成。
*   **3D プリミティブ**: 直方体(Box)、球、円柱、円錐、角錐の生成。
*   **ブール演算**: ソリッドに対する和(Fuse)、積(Common)、差(Cut)演算の実行。
*   **板金コネクタ**: 選択した2つの面を直交経路の板金で接続し、円弧曲げ、溶接またはボルト/ナット端部、干渉チェックに対応。
*   **変形・編集**:
    *   **ミラー**: 平面または軸によるオブジェクトの鏡像作成。
    *   **パターン**: 線形および円形パターンの作成。
    *   **シェル**: ソリッドをシェル（中空）構造に変換。

### 📏 計測と解析
*   **計測**: 距離、エッジ長、円弧長/半径、角度を測定する精密ツール。
*   **解析**: オブジェクト間の干渉チェック。
*   **アセンブリ可視化**: 内部コンポーネントを検査するための分解ビュー(Exploded View)。
*   **クリッピング**: 断面ビューを確認するためのクリッピング平面の適用。

### ⚙️ ユーティリティとカスタマイズ
*   **トランスフォーム**: オブジェクトの移動、回転、拡大縮小を行うインタラクティブツール。
*   **作業平面**: 設定可能な座標系ヘルパー。
*   **選択フィルタ**: 頂点、エッジ、面、ソリッドによる選択フィルタリング。
*   **テーマ対応**: ライトテーマとダークテーマの切り替え。
*   **ローカライズ**: 多言語サポート。

## 🛠️ 技術スタック

*   **C++**: アプリケーションのコアロジックは最新のC++ (C++17標準) で記述されています。
*   **Qt Framework**: GUI全体に使用され、SARibbonを使用してモダンなリボンスタイルのツールバーを実現しています。
*   **OpenCASCADE Technology (OCCT)**: すべてのCAD操作を処理する強力なオープンソース3D幾何形状モデリングカーネル。
*   **CMake**: プロジェクトの構成とビルドに使用されるクロスプラットフォームビルドシステム。

## 🚀 はじめに

以下の手順に従って、開発およびテスト目的でローカルマシン上にプロジェクトのコピーをセットアップしてください。

### 前提条件

システムに以下のソフトウェアがインストールされている必要があります。

*   **C++17準拠のコンパイラ**:
    *   Windows: MSVC 2019 以降
*   **CMake**: バージョン 3.16 以上。
*   **Qt Framework**: バージョン 6.2 以上。コンパイラに一致するコンポーネントをインストールしてください。
*   **OpenCASCADE Technology (OCCT)**: バージョン 7.6.0 以上。

### コンパイル手順

1.  **リポジトリのクローン**

    ```bash
    git clone https://github.com/bezierC0/Qt_OCC.git
    cd Qt_OCC
    ```

2.  **ビルドディレクトリの作成**

    ```bash
    mkdir build
    cd build
    ```

3.  **CMakeでの構成**

    QtおよびOCCTのインストールパスを正しく設定してください。

    ```bash
    # Windows Visual Studio の例
    cmake .. -G "Visual Studio 17 2019" -A x64 \
    -DQt5_DIR="C:/Qt/5.15.2/msvc2019_64/lib/cmake/Qt5" \
    -DOpenCASCADE_DIR="C:/Libs/OCCT/occt-7.8.0-vc14-64" \
    -DOpenCASCADE_3RDPARTY_DIR="C:/Libs/OCCT/3rdparty-vc14-64"
    ```

4.  **プロジェクトのビルド**

    ```bash
    cmake --build . --config Release
    ```

5.  **アプリケーションの実行**

    実行ファイルは `build/bin/Release` (Windows) または `build/bin` (Linux) ディレクトリに生成されます。

### 点群のインポート

1. **ファイル > インポート**を開きます。
2. `.xyz`、`.txt`、`.pts`、`.ply`ファイルを選択します。
3. **点群**パネルで統計情報を確認し、表示設定を変更します。
4. **点群をフィット**を使用して、点群全体をビューに収めます。

別のモデルまたは点群をインポートすると、現在のシーンは置き換えられます。Binary Big Endian PLY、PCD、LAS/LAZ、位置合わせ、フィルタリング、サーフェス再構築には現在対応していません。点群の読み込み中は、CAD／CAE専用コマンドを使用できません。

手動テスト用ファイルは[`samples/pointcloud`](../../samples/pointcloud)にあります。`binary_colored_cube.ply`は、プロパティ順序が混在しRGBデータを含むBinary Little Endian PLYの確認用です。
